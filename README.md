# Ring a Bell (OpenMW)

You have a Sixth House Bell Hammer, yet can't ring bells with it? Well, not anymore!

*For MESE alternative check out [Ring a Bell](https://www.nexusmods.com/morrowind/mods/56342) by C3pa.*

## Supported Mods

- [Tamriel_Data](https://www.nexusmods.com/morrowind/mods/44537)
- [Bell Towers of Vvardenfell](https://www.nexusmods.com/morrowind/mods/52523)

## Requirements

Load order doesn't matter.

- [Impact Effects](https://www.nexusmods.com/morrowind/mods/55508)

Also supports Tamriel_Data.
